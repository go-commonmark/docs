# commonmark

Strict CommonMark v0.31.2 Markdown-to-HTML renderer — 652/652 spec, byte-exact, GFM behind Options.

## Install

```bash
go get github.com/go-commonmark/commonmark
```

Requires Go 1.26.4 or newer. `CGO_ENABLED=0`.
